# Flippy Do

An interactive binary place-value tool and lesson article for a high school Digital Information unit.

## Pages

- `index.html`: 4-, 8-, and 12-bit folding-flap tool, decimal targets, and hidden totals.
- `lessons.html`: eight mini lessons with interactive examples and practice.

Open `index.html` in a browser. No dependencies or build step are required.

## GitHub Pages

Publish from the `main` branch and `/ (root)` folder in Settings → Pages.
