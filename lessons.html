Binary, one idea at a time.

We already use place value every day. Now we’ll use that same idea with just two digits.

Read these lessons in order. Each one builds on the last. Try the examples, make a prediction, and then check your thinking. You can return to the Flippy Do whenever you want to test an idea.

01 / THE DIGIT SUPPLY

A base tells us which digits we can use.

Our usual number system is decimal, or base 10. It has ten digits: 0 through 9. Binary, or base 2, has two digits: 0 and 1.

The base does not change the amount we are counting. It changes how we write that amount. Think of it as a different set of rules for writing numbers.

Same amount, different writing

Decimal
6
Binary
110

The amount stays the same. Only the written form changes.

02 / POSITION CARRIES MEANING

The same digit can have a different value.

In 3,472, the 4 is worth 400. In 4,000, the 4 is worth 4,000. The digit stays the same, but its position changes its value.

We call this place value. Position lets us write large amounts using a small set of symbols.

Move the 4

4 × 100 = 400

Every other place is zero in this example.

The base gives us a set of digits. Place value lets us use those digits in different positions to represent more numbers.

Teacher tip: digit vs. value

When I ask for a digit, name the symbol. When I ask for its value, include the amount its position gives it. In 400, the digit is 4 and its value is 400.

03 / THE MULTIPLIER

Each step left multiplies by the base.

Start at the right with the ones place. In decimal, multiply by 10 each time you move left: 1, 10, 100, 1,000. In binary, multiply by 2: 1, 2, 4, 8.

These values are powers of the base. The exponent counts how many times we multiply, starting with an exponent of zero on the right. Both 10⁰ and 2⁰ equal 1.

Compare the columns

Place value gives us the columns. The base tells us how much larger each column is than the one to its right.

04 / RUNNING OUT OF DIGITS

When a column fills, we carry.

In decimal, 9 is the last single digit. Add one more and we write 10: one ten and zero ones. In binary, 1 is the last single digit. Add one more and we write 10: one two and zero ones.

We reset the full column to zero and add one to the column on its left. That column may need to carry, too. For example, binary 11 becomes 100 when we add one.

Count and watch for a carry

Decimal 0 → Binary 0000

Count from 0 to 15. Watch what happens after 1, 3, and 7.

It takes two units of a binary column to make one unit of the next column. That is why the column values double.

Try a prediction

What comes after binary 0111? The three rightmost columns all carry. The result is 1000, which represents decimal 8.

05 / SAME SYMBOLS, DIFFERENT BASE

Binary “10” means two.

The symbols 10 do not tell us the base by themselves. In decimal, they mean one ten and zero ones. In binary, they mean one two and zero ones.

10 in base 10

(1 × 10) + (0 × 1)

= ten

10 in base 2

(1 × 2) + (0 × 1)

= two

In our class, say binary 10 as “one-zero”. That keeps it clear which digits you mean. We can also write 10₂ to show the base.

The written digits look the same in both bases. The column values give them their meaning.

06 / INCLUDE IT OR SKIP IT

Read binary by adding the columns with a 1.

A 1 means “include this column’s value.” A 0 means “skip it.” For binary 1011, include 8, skip 4, and include 2 and 1. The total is 11.

We do the same kind of work in decimal: 3,472 is (3 × 1,000) + (4 × 100) + (7 × 10) + (2 × 1). In binary, each multiplier is just 0 or 1.

Build a number

Click a bit to include or skip its place value.

Hint

Write 16, 8, 4, 2, 1 above the digits. Which values have a 1 under them?

Go the other direction: decimal to binary

To make decimal 21, start with the largest column that fits: 16. That leaves 5. Skip 8, include 4, skip 2, and include 1. You have 10101. Use the Flippy Do to try another target.

08 / WHY COMPUTERS USE BINARY

Two reliable states match two digits.

Inside a computer, electronic circuits use two signal states to represent 0 and 1. We often describe these states as “off” and “on,” or “low” and “high.” Real circuits are more complex, but the key idea is that they can reliably tell two states apart.

Those two states match binary’s two digits. Computers can use patterns of bits to represent numbers and, with agreed rules, text, images, sound, and program instructions.

One binary digit is a bit. Eight bits make a byte. Eight bits have 2⁸ = 256 possible patterns. If we use those patterns for unsigned whole numbers, the values run from 0 through 255.

More bits, more possible patterns

Why 256 values, but a largest value of 255?

Zero counts as one of the values. From 0 through 255, there are 256 values. Also, the largest eight-bit whole number has every bit on: 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.

PUT THE IDEAS TOGETHER

Explain your thinking.

Try explaining these aloud or writing a few sentences before opening the answers. Use column values and carrying to support your explanation.

  1. Why does binary 100 equal decimal four?
  2. Why does a byte have 256 patterns instead of 255 or 100?
  3. Why do decimal 9 → 10 and binary 1 → 10 look alike but represent different amounts?
Compare your explanation
  1. The third column from the right is worth 2², or 4. So 100₂ includes one 4 and skips the 2 and 1.
  2. Eight bits each have two possible states. That gives 2⁸ = 256 patterns, including the all-zero pattern.
  3. Both systems carry when a column runs out of digits. Decimal carries after 9, making one ten. Binary carries after 1, making one two.

Remember the connection: the base tells us which digits we have and how the column values grow. Carrying and conversion follow from those rules.
